# jankenpo-rpa

> A ordem dos passos importa: nao pule a preparacao do ambiente.


Dá para montar um projeto inteiro usando a ideia de "pouco código", encaixando blocos em vez de escrever linha por linha. A cabeça de programador continua sendo necessária — o que muda é que o texto do código vira uma sequência de caixas.

Para abrir este projeto, importe o arquivo pelo gerenciador de projetos da ferramenta, conforme a imagem abaixo mostra.

![como importar](help-to-import-project.png)

O arquivo a importar é o `Jankenpo.uip`, que fica na raiz do repositório.

As páginas que o robô acessa são HTML bem simples, mantidas na pasta `jankenpo-external`.

Há um vídeo da execução completa, caso queira ver antes de tentar.

* Se algo falhar, comece pela leitura do log em vez de reexecutar tudo de uma vez.
